# Imagens do projeto

Esta pasta é destinada às imagens utilizadas na documentação do projeto.

Podem ser adicionadas aqui, por exemplo:

- capturas de tela da configuração;
- imagens do resultado final;
- diagramas;
- outras imagens úteis para explicar a implementação.

As imagens de identidade visual utilizadas na personalização do 4get ficam na pasta `custom/`, pois fazem parte diretamente da configuração visual da aplicação.

A pasta `images/` é reservada para materiais de documentação.

No estado atual do projeto, nenhuma imagem adicional de documentação é necessária.
