# Arquivos de personalização

Esta pasta contém os arquivos utilizados para personalizar visualmente o 4get.

Os arquivos presentes aqui são exemplos genéricos e podem ser substituídos pelos materiais criados para cada projeto.

## Estrutura

custom/
├── favicon-exemplo.ico
├── wallpaper-exemplo.jpg
├── banner/
│   └── banner-exemplo.png
└── README.md

## Favicon

O arquivo `favicon-exemplo.ico` representa o ícone exibido pelo navegador.

Para utilizar sua própria identidade, substitua esse arquivo pelo favicon desejado.

## Banner

A pasta `banner/` contém o banner utilizado na página inicial do 4get.

O arquivo `banner-exemplo.png` serve apenas como exemplo de estrutura.

Substitua-o pelo banner preparado para o seu projeto, mantendo o nome e a localização esperados pela configuração.

## Wallpaper

O arquivo `wallpaper-exemplo.jpg` representa a imagem utilizada como fundo da página.

A imagem pode ser substituída por qualquer wallpaper preparado para o projeto.

No exemplo original da TuxFreeTech, o wallpaper recebeu uma camada escura através do CSS para permanecer discreto e não atrapalhar a leitura da página.

## Identidade visual

Os materiais desta pasta são exemplos genéricos.

Eles não utilizam os arquivos de identidade visual reais da TuxFreeTech, permitindo que o projeto seja reproduzido sem depender dos materiais proprietários da marca.

A ideia é simples: use a estrutura técnica como base e coloque nela a sua própria identidade visual.
