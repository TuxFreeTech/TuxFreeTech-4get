# Assets visuais de exemplo

Estes arquivos são exemplos genéricos para demonstrar a estrutura da
personalização do 4get.

Eles não utilizam a identidade visual da TuxFreeTech e podem ser substituídos
pelas imagens criadas para o seu próprio projeto.

## Estrutura

```text
custom/
├── favicon-exemplo.ico
├── wallpaper-exemplo.jpg
├── banner/
│   └── banner-exemplo.png
└── README.md
```

Use os exemplos para entender o formato e o local dos arquivos. Substitua-os
por sua própria identidade visual quando reproduzir o projeto.
