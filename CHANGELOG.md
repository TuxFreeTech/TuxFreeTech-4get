# Changelog

Registro das principais alterações do projeto TuxFreeTech 4get.

## Versão inicial

### Adicionado

- Personalização visual do 4get para o ambiente TuxFreeTech.
- Nome personalizado através do Docker Compose.
- Favicon personalizado.
- Banner personalizado.
- Wallpaper aplicado de forma discreta através do CSS.
- Estrutura de arquivos personalizados separada da aplicação original.
- Documentação do processo de implementação, erros, correções e manutenção.
- Exemplos visuais genéricos para permitir a reprodução da técnica.
- Política de uso dos materiais de identidade visual da TuxFreeTech.

### Preservado

- Funcionamento original do mecanismo de busca.
- Configurações de busca utilizadas no ambiente original.
- Tema escuro.
- Estrutura principal do 4get.
- Possibilidade de atualização da aplicação sem incorporar os arquivos proprietários da TuxFreeTech.

### Observação

Os materiais de identidade visual originais da TuxFreeTech não fazem parte deste repositório. Os exemplos disponibilizados servem apenas para demonstrar a estrutura e podem ser substituídos pelos materiais criados para cada projeto.
